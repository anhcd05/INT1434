# INT1434 - Lập trình Web

Chử Đức Anh - B23DCAT004

## Bài thực hành 1: InfoSound

Giao diện nền tảng chia sẻ và nghe nhạc cộng đồng bằng ReactJS (Vite + React Router). Mã nguồn ở [`infosound/infosound/`](infosound/infosound/).

```bash
cd infosound/infosound
npm install
npm run dev      # mở http://localhost:5173
```
