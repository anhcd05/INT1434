# INT1434 - Lập trình Web

Sinh viên: **Chử Đức Anh** - B23DCAT004

## Bài thực hành 1: InfoSound

Giao diện nền tảng chia sẻ và nghe nhạc cộng đồng, viết bằng ReactJS (Vite + React Router).

| Thư mục | Nội dung |
|---------|----------|
| [`infosound/infosound/`](infosound/infosound/) | Mã nguồn dự án (xem README bên trong) |
| [`bao_cao/`](bao_cao/) | Báo cáo LaTeX (`bao_cao.tex`) và bản PDF (`bao_cao.pdf`) |
| [`poc_image/`](poc_image/) | Ảnh chụp 10 trang dùng trong báo cáo |

### Chạy dự án

```bash
cd infosound/infosound
npm install
npm run dev      # mở http://localhost:5173
```

### Biên dịch báo cáo

```bash
cd bao_cao
pdflatex bao_cao.tex
pdflatex bao_cao.tex
```
